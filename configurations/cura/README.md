# Cura Profiles

This directory contains Cura slicer profiles for various 3D printers.

## Structure

Organize profiles by printer type:
```
cura/
├── ender3-profiles/
│   ├── quality-profiles/
│   ├── material-profiles/
│   └── README.md
├── cr10-profiles/
└── custom-profiles/
```

## Adding a Profile

1. Create a folder with your printer model name
2. Export your profiles (quality, material, printer settings)
3. Include a README.md with:
   - Cura version
   - Printer specifications
   - Profile purposes (speed, quality, etc.)
   - Supported materials
   - Date created
