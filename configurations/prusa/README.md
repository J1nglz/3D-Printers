# PrusaSlicer Profiles

This directory contains PrusaSlicer configuration profiles for various 3D printers.

## Structure

Organize profiles by printer type or purpose:
```
prusa/
├── ender3-profiles/
│   ├── config.ini
│   ├── filament-profiles/
│   └── README.md
├── voron-profiles/
└── custom-material-profiles/
```

## Adding a Profile

1. Create a folder with a descriptive name
2. Export your configuration bundle or individual profiles
3. Include a README.md with:
   - PrusaSlicer version
   - Printer(s) the profiles are for
   - Notable settings or optimizations
   - Materials/filaments supported
   - Date created
