# OrcaSlicer Profiles

This directory contains OrcaSlicer configuration profiles for various 3D printers.

## Structure

Organize profiles by printer type:
```
orcaslicer/
├── bambu-lab/
│   ├── profiles/
│   └── README.md
├── voron-profiles/
└── multi-material-profiles/
```

## Adding a Profile

1. Create a folder with your printer model name
2. Export your configuration profiles
3. Include a README.md with:
   - OrcaSlicer version
   - Printer specifications
   - Profile features and optimizations
   - Supported materials
   - Date created
