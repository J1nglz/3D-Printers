# 3D Printer Profile Repositories

This document contains references to external git repositories that host 3D printer profiles, configurations, and related resources.

## Firmware Configuration Repositories

### Marlin Firmware
- **[Marlin Firmware](https://github.com/MarlinFirmware/Marlin)** - Main Marlin firmware repository
- **[Marlin Configurations](https://github.com/MarlinFirmware/Configurations)** - Pre-configured Marlin configurations for many printers
- **[TH3D Unified Firmware](https://github.com/th3dstudio/TH3DUF_Releases)** - User-friendly Marlin-based firmware

### Klipper Firmware
- **[Klipper](https://github.com/Klipper3d/klipper)** - Main Klipper 3D printer firmware
- **[Klipper Config](https://github.com/Klipper3d/klipper/tree/master/config)** - Example configurations included with Klipper
- **[Voron Users Mods](https://github.com/VoronDesign/VoronUsers)** - Community Klipper configs for Voron printers

### RepRap Firmware
- **[RepRapFirmware](https://github.com/Duet3D/RepRapFirmware)** - Advanced firmware for Duet boards
- **[Duet3D Config Examples](https://github.com/Duet3D/ConfigFiles)** - Example configurations for various printers

## Slicer Profile Repositories

### PrusaSlicer
- **[PrusaSlicer](https://github.com/prusa3d/PrusaSlicer)** - Main PrusaSlicer repository with bundled profiles
- **[PrusaSlicer Profiles](https://github.com/prusa3d/PrusaSlicer-settings)** - Configuration bundles for various printers

### Cura
- **[Cura](https://github.com/Ultimaker/Cura)** - Main Cura slicer repository
- **[Cura Resources](https://github.com/Ultimaker/Cura/tree/main/resources)** - Built-in printer definitions and profiles
- **[Community Cura Profiles](https://github.com/trouch/CrealityEnder3-Settings)** - Community profiles for Ender 3

### OrcaSlicer
- **[OrcaSlicer](https://github.com/SoftFever/OrcaSlicer)** - Main OrcaSlicer repository with profiles
- **[OrcaSlicer Profiles](https://github.com/SoftFever/OrcaSlicer/tree/main/resources/profiles)** - Built-in printer profiles

### SuperSlicer
- **[SuperSlicer](https://github.com/supermerill/SuperSlicer)** - PrusaSlicer fork with additional features

## Printer-Specific Configuration Repositories

### Voron Printers
- **[Voron Design](https://github.com/VoronDesign)** - Official Voron printer designs and configs
- **[Voron Users](https://github.com/VoronDesign/VoronUsers)** - Community mods and configurations
- **[Voron Documentation](https://github.com/VoronDesign/VoronDocs)** - Comprehensive documentation

### Creality Printers
- **[Ender 3 Marlin Configs](https://github.com/MarlinFirmware/Configurations/tree/import-2.1.x/config/examples/Creality)** - Official Marlin configs for Creality printers
- **[Professional Firmware](https://github.com/mriscoc/Ender3V2S1)** - Enhanced firmware for Ender 3 V2/S1

### Prusa Printers
- **[Prusa Firmware](https://github.com/prusa3d/Prusa-Firmware)** - Firmware for Original Prusa i3 MK2/MK3
- **[Prusa Firmware MK4](https://github.com/prusa3d/Prusa-Firmware-Buddy)** - Firmware for MK4 and XL
- **[Prusa MMU2S Firmware](https://github.com/prusa3d/MM-control-2.0)** - Multi-Material Unit firmware

### Bambu Lab
- **[Bambu Studio](https://github.com/bambulab/BambuStudio)** - Official Bambu Lab slicer
- **[Bambu Network Protocol](https://github.com/Doridian/OpenBambuAPI)** - Community reverse-engineered API

### AnyCubic
- **[AnyCubic Configurations](https://github.com/MarlinFirmware/Configurations/tree/import-2.1.x/config/examples/AnyCubic)** - Marlin configs for AnyCubic printers

### Artillery
- **[Artillery Configurations](https://github.com/MarlinFirmware/Configurations/tree/import-2.1.x/config/examples/Artillery)** - Marlin configs for Artillery printers
